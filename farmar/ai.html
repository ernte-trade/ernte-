1 · Kľúč Claude (povinné)

  1. Otvor console.anthropic.com → API Keys a prihlás sa.
  2. Billing → pridaj kartu a kredit (napr. 20 $).
  3. Create Key → názov „ERNTE“ → skopíruj kľúč (začína sk-ant-).

2 · Úpravy aplikácie cez AI

  1. Otvor GitHub → nový token.
  2. Názov „ERNTE AI“, platnosť 1 rok. Repository access → Only select → ernte-trade/ernte-.
  3. Permissions → Repository → Issues: Read and write → Generate → skopíruj.
